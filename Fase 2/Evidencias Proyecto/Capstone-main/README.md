# Capstone
This is a repository for the development of the Capstone project, and the iteration therein.

## Stock management dashboard

This project includes a clean, modern stock management webpage with:
- KPI summary cards
- searchable inventory table
- low-stock watchlist
- quick-add stock form
- responsive layout for desktop/mobile

### Run locally

From the project folder, start a simple local server that serves the `public` folder:

```bash
python -m http.server 8000 --directory public
```

Then open http://localhost:8000 in the browser. Keep the server running while using the page. If port 8000 is already in use, choose another port in the command and URL.
